# صانع صفحة سياسة الخصوصية والشروط (App Privacy Policy & Terms Generator)

أداة ويب حديثة وتفاعلية مستوحاة من مشروع [App Privacy Policy Generator](https://app-privacy-policy-generator.firebaseapp.com/) للمطور Nishant Srivastava، مع إعادة تصميم كاملة وعصرية (Modern UI/UX) وتطوير شامل ليتوافق بدقة مع أحدث متطلبات متجر **Google Play Console (Data Safety 2026)** ومتجر **Apple App Store** ولوائح **GDPR** و **COPPA**.

## 🌟 أبرز المميزات والإضافات مقارنة بالموقع الأصلي

1. **معاينة حية ومباشرة (Real-Time Live Preview):**
   - ينقسم التصميم على الشاشات الكبيرة إلى نصفين (Split-Screen): معالج الإعدادات على جانب، والمعاينة الحية على الجانب الآخر تتحدث فورياً لحظة بلحظة مع كل حرف أو خيار تقوم بتعديله.

2. **دعم ثنائي كامل للغة (Bilingual UI & Bilingual Policies):**
   - **واجهة مستخدم ثنائية اللغة:** التبديل بضغطة زر بين العربية والإنجليزية مع دعم كامل لاتجاه النص (RTL / LTR).
   - **توليد الوثائق بلغتين:** إمكانية توليد الوثيقة باللغة **الإنجليزية** (المطلوبة دائماً لقبول التطبيق في Google Play و App Store) أو باللغة **العربية** (للتطبيقات والمواقع العربية).

3. **توليد وثيقتين في أداة واحدة:**
   - 📄 **سياسة الخصوصية (Privacy Policy)**
   - 📜 **الشروط والأحكام (Terms & Conditions)**

4. **مكتبة موسعة لخدمات الطرف الثالث (25+ Third-Party SDKs):**
   - إعلانات: Google AdMob, Meta Audience Network, Unity Ads, AppLovin, ironSource, StartApp, InMobi.
   - تحليلات وتشخيص: Firebase Analytics, Crashlytics, Sentry, Mixpanel, Amplitude, Adjust, AppsFlyer.
   - سحابة ومصادقة: Google Play Services, Firebase Auth/DB, Supabase.
   - إشعارات وخرائط: OneSignal, FCM, Google Maps, Mapbox.
   - اشتراكات ومدفوعات: RevenueCat, Stripe, Google Play Billing, Apple In-App Purchase.
   - **روابط رسمية مدمجة تلقائياً** لسياسة خصوصية كل خدمة يتم اختيارها لتفادي رفض التطبيق في المتاجر.

5. **قوالب سريعة بنقرة واحدة (Quick Presets):**
   - 🎮 **لعبة مع إعلانات (Ad-Supported Game):** إعداد مسبق لـ AdMob + Unity Ads + Crashlytics.
   - 🛒 **متجر إلكتروني (E-Commerce):** إعداد مسبق للمدفوعات عبر Stripe + OneSignal + الحسابات وحذف البيانات.
   - ⚡ **أداة بدون تتبع (Zero-Tracking Utility):** لتطبيقات الأدوات البسيطة دون جمع بيانات.
   - 🌟 **خدمة باشتراك وسحابية (SaaS / Freemium):** إعداد مسبق لـ RevenueCat + Supabase + Sentry.

6. **تصدير متعدد الصيغ:**
   - 📋 **نسخ بنقرة واحدة** إلى الحافظة.
   - 💾 **تحميل ملف HTML مستقل تماماً** يحتوي على التنسيق والخطوط مدمجة بداخله ولا يحتاج لأي ملفات خارجية (جاهز للرفع فوراً على أي استضافة).
   - 💾 **تحميل ملف Markdown (.md)** جاهز للاستخدام في GitHub (`PRIVACY_POLICY.md`).
   - 📄 **نص عادي (Plain Text)** للمستندات والرسائل.
   - 🖨️ **طباعة أو تصدير PDF** بتنسيق مخصص للطباعة يُخفي الأزرار ويُنسق الوثيقة القانونية بأعلى احترافية.
   - 🚀 **فتح في صفحة مستقلة بنقرة واحدة (Open Live View)** لمشاهدة كيف ستبدو للمستخدمين.

7. **الامتثال لمتطلبات حذف الحساب (Account & Data Deletion):**
   - تضمين بند صريح برابط أو بريد طلب حذف البيانات والحساب، وهو شرط إلزامي حديث لقبول التطبيقات على Google Play و App Store.

8. **الوضع الليلي والنهاري (Dark / Light Mode):**
   - دعم الوضع الليلي المريح للعين مع حفظ تفضيل المستخدم في `localStorage`.

## 🚀 كيفية التشغيل محلياً (Run Locally)

المشروع مبني بأسلوب Single-Page Web Application بدون أي حاجة لأوامر تثبيت معقدة أو أدوات بناء (Zero-build setup).

### الطريقة 1: الفتح المباشر
- انقر نقراً مزدوجاً على ملف `index.html` ليفتح في أي متصفح ويب حديث (Chrome, Edge, Safari, Firefox).

### الطريقة 2: تشغيل سيرفر محلي عبر Python
```bash
python -m http.server 8000
```
ثم افتح المتصفح على: `http://localhost:8000`

### الطريقة 3: تشغيل سيرفر محلي عبر Node.js
```bash
npx serve .
```

## 🌐 خطوات نشر صفحة السياسة مجاناً والحصول على رابط لمتجر Google Play

متجر **Google Play Console** يتطلب رابطاً نشطاً (URL) متاحاً للعامة لسياسة الخصوصية. إليك أسهل الطرق لنشر ملف الـ HTML المولد مجاناً:

### الخيار 1: عبر GitHub Pages (الأكثر شيوعاً والمجانية تماماً)
1. من داخل الموقع، اضغط على **"تحميل HTML"** وسيتم تنزيل ملف باسم `privacy-policy.html`.
2. أنشئ مستودعاً جديداً (Public Repository) على حسابك في GitHub باسم مثل `my-app-privacy`.
3. ارفع الملف وقم بإعادة تسميته إلى `index.html`.
4. اذهب إلى **Settings > Pages** واختر الفرع `main` ثم اضغط **Save**.
5. ستحصل على رابط مثل: `https://yourusername.github.io/my-app-privacy/`
6. ضع هذا الرابط في Google Play Console تحت **محتوى التطبيق (App Content) > سياسة الخصوصية (Privacy Policy)**.

### الخيار 2: عبر Netlify Drop (خلال 30 ثانية)
1. حمّل ملف `privacy-policy.html` وأعد تسميته إلى `index.html` وضعه في مجلد.
2. ادخل على [app.netlify.com/drop](https://app.netlify.com/drop) واسحب المجلد هناك مباشرة.
3. ستحصل على رابط مباشر فوري مجاني دائم (مثل `https://my-app-policy.netlify.app`).
